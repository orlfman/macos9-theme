# Platinum bottom tabs for Kwi

**Status:** Implemented 2026-11-24 by Claude (Opus 5.5) for Kwi and Konsole bottom tabs; see CHANGELOG.md and AUDIT.md. Checked offscreen (`dev/check-tabs.sh` 50/50 after Codex's #236–237 and Gemini's #238–239, including a Qt Quick footer fixture) and in nested KWin with Kwi and Konsole at 100%. 150% and 200% nested checks, tab dragging and overflow scrolling were not exercised.

## Feasibility

**Yes. Kwi’s footer tabs can reuse the Platinum Qt Widgets tab renderer through KDE’s existing Qt Quick style bridge.** The installed Kwi build identifies itself as `0.1.0.r35.g5028051-1`. Its source at that revision uses a standard Qt Quick Controls `TabBar` and derives its terminal tab delegate from a standard `TabButton`. Kwi supplies the tab’s title, icon, close button, progress indicator, and drag behavior, while the inherited style supplies the tab face. The main window passes `TabBar.Footer` when the tab bar is configured at the bottom. [Kwi tab strip](https://github.com/KDE/kwi/blob/502805151a6f276116337757648796343862ab71/src/declarative/TerminalTabs.qml#L167-L255) · [Terminal tab delegate](https://github.com/KDE/kwi/blob/502805151a6f276116337757648796343862ab71/src/declarative/TerminalTabButton.qml#L16-L145) · [Footer configuration](https://github.com/KDE/kwi/blob/502805151a6f276116337757648796343862ab71/src/declarative/Main.qml#L1075-L1086)

The Platinum Qt Quick module imports KDE’s desktop style as its fallback. In the installed `qqc2-desktop-style` 6.32.0, the fallback `TabButton` renders through a KDE style item. That item converts the footer orientation to `QTabBar::RoundedSouth` and calls `QStyle::CE_TabBarTab`. Platinum currently draws its custom tab face and label for north-facing shapes, so south-facing tabs fall through to the base style. The first implementation should use this existing path and require no Kwi patch or additional Qt Quick tab component. [Platinum module](../style/quick/Platinum/qmldir) · [KDE TabButton](https://github.com/KDE/qqc2-desktop-style/blob/v6.32.0/org.kde.desktop/TabButton.qml#L49-L105) · [KDE orientation mapping](https://github.com/KDE/qqc2-desktop-style/blob/v6.32.0/plugin/kquickstyleitem.cpp#L442-L474) · [KDE paint dispatch](https://github.com/KDE/qqc2-desktop-style/blob/v6.32.0/plugin/kquickstyleitem.cpp#L1775-L1780) · [Platinum tab rendering](../style/platinum/platinumstyle.cpp#L1605)

## Proposed implementation

1. Extend the shared C++ tab face renderer to handle `RoundedSouth`. Reverse the measured north tab rows vertically while preserving their horizontal positions. Use the existing normal, selected, and pressed artwork. The selected tab’s opening should meet the terminal above it. Treat the mirrored bevel as a derived Platinum design and compare it against a vertically flipped copy of the existing renderer output.
2. Keep the label, icon, close control, progress bar, and focus rectangle upright. Kwi supplies its own content and passes a blank native title to prevent double drawing. Check the content area at Kwi’s actual tab height before changing global tab metrics. Stretch or fill the interior if a taller control needs coverage. Keep the edge and seam rows at their intended thickness.
3. Check the seam in Kwi before extending the Qt Widgets tab base. Kwi disables the standard `TabBar` background and draws a separate separator with a gap for the selected tab. Align the mirrored face to that gap. If the existing style hooks cannot make the seam continuous, document the limit and scope any further change to a supported upstream hook. [Kwi’s separator and selected-tab gap](https://github.com/KDE/kwi/blob/502805151a6f276116337757648796343862ab71/src/declarative/Main.qml#L995-L1022)
4. Keep the shared change orientation-based. A regular Qt Widgets app with bottom tabs can pick up the same treatment. The existing measured north tabs are the regression baseline.

## Acceptance checks

- Extend the Qt Widgets style fixture to compare south tab faces against flipped north faces at 100% scale. Cover normal, selected, pressed, and disabled states, plus the pane seam.
- Cover a footer `TabBar` in the Qt Quick fixture with Platinum enabled through its normal style fallback. Confirm the south face renders and check keyboard focus, tab sizing, and right-to-left layout. Run the existing style and Qt Quick checks for regressions.
- Launch the pinned Kwi version in a disposable nested session. Compare top and bottom tabs at 100%, 150%, and 200%. Inspect the seam, title contrast, close-button feedback, progress indicator, and clipping with narrow tabs. Exercise tab switching, closing, reordering, overflow scrolling, and the New Tab button.
